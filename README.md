## Key Features

- **718+ Service Presets & Custom Apps**: Messenger, WhatsApp, Telegram, Zalo, Instagram Direct, Discord, Slack, and custom URLs in one sidebar.
- **Multi-Account Isolation**: Each added service gets its own isolated WebKit data store so two accounts stay separate.
- **Touch ID & Master Password Lock**: Native macOS `LocalAuthentication` unlock, auto-lock timer, and custom lock screen.
- **Tablet & Foldable Split-View**: Responsive layout keeps conversation list and active thread side by side.
- **Vietnamese IME Compatibility**: Prevents doubled characters and lost accents with EVKey, OpenKey, and Laban Key.
- **Native macOS Integration**: Liquid Glass window, Dock badge, native notifications, Do Not Disturb, and Sparkle auto-updates.
