# another.Messenger

Lightweight, multi-service chat client optimized for tablet/foldable dual-pane split-view and native IME compatibility.

Supports **Messenger**, **WhatsApp**, **Telegram**, and **Zalo** in a unified shell.

---

## Downloads

Download the latest binaries for your platform from the [Releases](https://github.com/jinkun1998/another.Messenger-releases/releases) page:

- **macOS:** `.dmg` (Apple Silicon & Intel)
- **Windows:** `.exe` (WebView2 / Chromium runtime)
- **Android:** `.apk` (Foldables & Tablets)

---

## Key Features

- **Tablet & Foldable Split-View:** Enforces permanent dual-pane layout (sidebar + active thread) on foldables and tablets.
- **IME Stabilization:** Zero character-doubling or lost accents when typing Vietnamese using EVKey, OpenKey, or Laban Key.
- **Low Footprint:** Native OS webview engine (Tauri v2). 1/10th the RAM usage of Electron.
- **Multi-Service Isolation:** Isolated session contexts to run multiple accounts simultaneously.
